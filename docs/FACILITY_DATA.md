# 施設情報とランドマーク

確認日：2026-09-29。

## 取得した情報

[上島町個別施設計画](https://www.town.kamijima.lg.jp/soshiki/2/19667.html)の2021年3月版から、対象施設一覧（PDF物理ページ7～11、本文4～8ページ）を抽出しました。83施設・167棟、延床面積合計80,130.34m²です。施設名、用途分類、建物名、所管、延床面積、構造、建築年月日を保持しています。

計画の本文や写真を転載せず、施設に関する事実情報を抽出しています。建物の劣化評価から安全性を推定する表示はしません。2021年以降の変更、現在の開設状況は別途確認が必要です。

位置は[町の公共施設ガイド](https://www.town.kamijima.lg.jp/site/publicfacilities/)、既存の国土地理院避難施設点、OpenStreetMap四国2026-09-27版の名称・位置を照合しました。町ガイドは29ページを確認し、8ページに施設位置を示す座標参照がありました。案内地図の中心・施設代表点を使用し、測量点や正確な入口位置ではありません。町ガイドの掲載日と位置の出典を施設詳細に表示します。

- 計画全83施設を `public/data/facility-plan.json` に収録。
- 位置を照合できた43施設を `public/data/public-facilities.geojson` に収録。
- 指定避難所24件、指定緊急避難場所13件へ計画情報を関連付け。
- 既存の避難施設件数・座標・対応災害の指定は変更していません。
- 学校と体育館等は施設全体の計画への関連付けです。複数計画に対応する魚島小・中学校は両計画を表示します。
- 40施設は位置未確認のため地図へ配置していません。住所からの推測や町の中心への仮配置はしていません。

## 表示と操作

通常の左ドラッグで移動、Ctrl＋左ドラッグで回転・傾きを操作します。ホイールで拡大縮小。タッチ操作は従来どおりです。

「公共施設（個別施設計画）」レイヤーを追加しました。施設名はズーム11.5以上で地形上の点から30px浮かせたラベルとして表示します。ラベルの高さは施設の実高さを意味しません。画面内の重なりを避け、PCは最大30件、モバイルは14件。行政施設を優先します。地形に隠れたラベルは非表示になります。

ラベル・施設点・検索結果を選ぶと、施設情報が右側（モバイルは下部）に表示されます。建物内訳から元PDFのページへ移動できます。計画との対応を確認できない避難施設は、その旨を表示し、既存の指定情報を残しています。

## 再生成・利用条件

`python scripts/build-facility-data.py` は公開カタログ内の確認済み対応表から地図・避難施設への関連付けを再生成できます。取得原本がある環境では `data/raw/facilities/plan-catalog.json` と `position-matches.json` を優先します。名称が似ているだけの施設や施設群を自動で新規に結び付けないでください。

町の文書・案内の出典と時点を維持してください。GSI位置情報は国土地理院の利用条件、OSM由来位置は© OpenStreetMap contributors / ODbL 1.0です。各施設の位置出典はカタログに保持しています。

## 検証

単体テスト52件、Edgeブラウザー回帰テスト30件、ESLint、TypeScript、静的ビルドが成功。通常ドラッグによる中心位置の変化、Ctrlドラッグによる方位・傾斜の変化、施設ラベルからの計画情報とPDF参照、検索での施設情報を確認しました。変更前の避難所44件・緊急避難場所121件と比較し、座標・指定属性の一致も照合しています。
