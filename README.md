# 上島町 統合防災WebGIS

公的な防災・地理データを地図に重ねる、非公式・非商用の防災参考サイトです。上島町・愛媛県の公式サービスではありません。広告・課金・分析トラッキングはありません。

## 機能

- 淡色地図／航空写真とDEM1A優先のHybrid Terrain。初期1倍、1.5/2倍切替。
- 津波浸水想定（国土数値情報2016年度版、3,332図形）と土砂災害区域の表示・地点判定。
- 地籍40,757筆の表示と地番検索、避難施設検索、座標入力、共有URL、A4印刷。
- 選択地点から徒歩1～60分で届く道路区間を、3D/2D地図上に表示。
- 4,306棟の推定3D建物、森林の模式樹冠、津波浸水深区分の模式立体表示。
- Official標高・出典・元解像度・品質区分、島別品質、DEM Coverage。
- カメラ・自動回転・光・軽量LOD、オフラインシェル、WebGL不可時の2D代替。

## データと制限

[出典と利用条件](DATA_SOURCES.md)を参照してください。各データの権利は配布元に帰属し、このリポジトリ全体に一律のオープンソースライセンスを付与するものではありません。

- 津波データは2016年度版で、最新の県想定と年次が異なります。過年度ページは防災・減災の公的利用（非商用）での再配信を認めています。
- 土砂データは出典を明記して加工。商用利用には県の許可が必要です。
- 地籍の測地系は原典にPRJがなく、第IV系を推定採用。作業CRSはEPSG:2446。JGD2000/JGD2011の判別は未確定で、筆界・権利の証明には使えません。
- 高潮・洪水は上島町付近の配信・収録を確認できないため空白になり得ます。県の最新公表図も確認してください。
- 震度・液状化等は利用条件確認待ち。建物の高さは全棟Estimatedです。DEM欠測の表示補間値は地点標高に使いません。
- NO_DATA・未着色・区域外は安全を意味しません。緊急時は町・県・気象庁等の最新情報を確認してください。
- 徒歩到達範囲はOpenStreetMapの2026-09-27版道路網と平地4km/hを基準にした目安です。任意でOfficial DEMによる勾配補正ができます。橋・トンネル・階段・標高欠測等は平地扱い。通行止め、未収録の道、渡船、個人差は未反映で、避難の安全性や実際の所要時間は示しません。

## 3Dの使い方

「3D設定」で真上・鳥瞰・地表付近、標高倍率、建物・森林・津波の立体表示を切り替えます。マウスはドラッグで回転、Shift＋ドラッグで傾き、タッチは2本指です。地点を選択するとOfficial標高と出典を確認でき、「徒歩での到達範囲」で時間・歩行モデルを指定できます。

「島ごとの地形品質」から各島へ移動、「Developer Mode」でDEM品質・タイル境界・描画情報を確認できます。初期表示は3D、明示的な2D共有URLは維持します。

設計・再生成：[TERRAIN_ARCHITECTURE.md](TERRAIN_ARCHITECTURE.md)。品質：[DEM_COVERAGE.md](docs/DEM_COVERAGE.md)。未対応・制約：[LIMITATIONS.md](LIMITATIONS.md)。

PWAは取得済みの画面・一部地図データを保存します。未取得範囲やPMTilesの完全オフライン表示は保証しません。現在地座標をアプリの永続データとして保存しませんが、閲覧した地図タイルはキャッシュ対象です。

## 起動・検証

Node.js 24、pnpm 11.19.0。

```sh
pnpm install --frozen-lockfile
pnpm lint
pnpm typecheck
pnpm test
pnpm build
pnpm serve
```

localhost:4173で閲覧できます。GitHub PagesはSettings → Pages → SourceをGitHub Actionsに設定します。mainへのpushでビルド・配信されます。NEXT_PUBLIC_BASE_PATHをPages設定から受け取り、地図データにも反映します。

公開ファイルはoutのみ。原本・中間データ・環境変数・個人PCの設定は含めません。データ整備日は画面の出典情報を参照してください。自動でデータ更新する仕組みはありません。

背景地図・航空写真・DEMには国土地理院等への通信が発生します。現在地は許可時のみ使用し、アプリで保存しません。共有URLには表示中心座標が含まれます。PagesのHTTPS配信では現在地機能も使用できます。
